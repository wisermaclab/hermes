# Security Policy

Please do not disclose security vulnerabilities in a public issue.

Use [GitHub's private vulnerability reporting
form](https://github.com/wisermaclab/hermes/security/advisories/new). If that
feature is unavailable, contact the repository maintainers privately through
the WiSeCom Lab organization.

Only supported public releases are covered by this policy. Restricted
datasets, external body models, and third-party tools are outside the scope of
the public HERMES repository.
