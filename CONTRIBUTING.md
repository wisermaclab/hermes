# Contributing to HERMES

Issues and proposed patches are welcome.

The public repository is synchronized from an authoritative internal
development repository. After the first source release, files listed in
`PUBLIC_SNAPSHOT.json` are managed by that synchronization process and should
not be merged directly here. For a change to managed source:

1. Open a public issue or pull request describing the change. A pull request
   serves as the reviewable patch and will not itself become the source of
   record.
2. A maintainer will apply or import the patch into the authoritative source,
   preserving contributor credit.
3. The audited synchronization workflow will publish the resulting change.

Public-repository governance files, including CI and security policy, are
maintained directly here and require maintainer review.
