# HERMES

HERMES (Human-Environment Radar ModEling and Simulation) is a Python toolkit
for mmWave FMCW radar simulation, physical-optics modeling, signal processing,
and reproducible validation workflows.

This repository is the public release mirror. Simulator source will be
synchronized here from the authoritative development repository only after an
automated public-tree audit, tests, and package inspection succeed.

The repository is currently in its governance bootstrap phase; no simulator
release has been published here yet.
