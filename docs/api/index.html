Start with the grouped experiment API

Use simulate_human_room(HumanRoomSettings(...)) for motion in a room, or simulate_static_target(StaticTargetSettings(...)) for plates, corners and static meshes. Settings group geometry/motion, scene, radar and solver options; use dataclasses.replace to vary one group.

from mmWaveRadar.experiments import (
    HumanMotionSettings, HumanRoomSettings, HumanRoomSolverSettings,
    RoomSceneSettings, simulate_human_room,
)

settings = HumanRoomSettings(
    motion=HumanMotionSettings(
        human_motion="/path/to/human_motion.npz",
        human_position_m=None,
        num_frames=2,
    ),
    scene=RoomSceneSettings(room_preset="empty_room"),
    solver=HumanRoomSolverSettings(solver="po"),
)
result = simulate_human_room(settings)

The flat run_human_room_experiment and run_static_target_experiment functions remain supported for compatibility. See the Python tutorial for grouped human/static examples and conversion of an existing CLI JSON.
